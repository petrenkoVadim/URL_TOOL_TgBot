## 📌 About the project

**URL-TOOL_TgBot** is a Telegram bot for working with video URLs. Just send a link — get a ready-to-use file back.

The bot is completely **free** and contains **no ads**. It has been thoroughly tested with:

- ✅ TikTok
- ✅ X (Twitter)
- ✅ Facebook

## ⚙️ Features

The bot has two main functions:

| Command | What it does |
|---|---|
| `/video` | Converts the video at the given URL into an **MP4** file in the best available quality |
| `/music` | Extracts the audio track from the video and sends it as a **Telegram audio** message |

## 🚀 How to use

1. Open the bot — [@url_to_mp4_bot](https://t.me/url_to_mp4_bot)
2. Send `/start`
3. Choose a mode:
   - `/video` — to get the video file
   - `/music` — to get just the audio
4. Paste the video URL (TikTok / X / Facebook)
5. Wait a few seconds — the bot will send you the ready file ✅
